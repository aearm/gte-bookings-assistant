Local data folder (used on Mac, or on Windows when DATA_SOURCE=local)

Put CSV, Excel (.xlsx) or Parquet files here. Each file becomes a table Claude can query.
The app re-reads this folder every time it starts (or click "Refresh data structure").

sample_bookings.csv is MADE-UP sample data for trying the app. Delete it when you add real data.

To try with real data: in Excel, put the data in a plain table (one header row, no merged
cells or subtotals), then File > Save As > CSV, and save it into this folder.
